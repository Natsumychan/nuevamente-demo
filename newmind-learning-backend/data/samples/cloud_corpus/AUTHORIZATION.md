# Autorización del corpus original

Los siguientes documentos son material sintético original creado con asistencia
de IA específicamente para la incidencia #60 de NewMind, a solicitud de
implementación del responsable del proyecto. No se copiaron documentos de
terceros ni documentación de Oracle en estos archivos:

- `cloud-networking.md`
- `cloud-operations.txt`
- `cloud-retention-table.pdf`
- `cloud-network-columns.pdf`

Estas muestras originales están autorizadas para su inclusión, reproducción,
modificación y reutilización en las pruebas y evaluaciones de ingesta de este
proyecto. Esta declaración se aplica únicamente a los cuatro archivos indicados;
no atribuye propiedad, licencia ni permisos a muestras anteriores, materiales
de Oracle u otros contenidos del repositorio.

Todos los escenarios, nombres de servicios, asignaciones de equipos y períodos
de retención son ilustrativos. No contienen identificadores de infraestructura
ni credenciales reales, y no constituyen una guía oficial del proveedor cloud
ni recomendaciones para producción.

Cada entrada del manifiesto registra esta procedencia y autorización de forma
independiente y vincula los bytes originales del documento mediante SHA-256.
Al modificar una muestra, se deben revisar sus expectativas de extracción y
actualizar su hash conjuntamente; los bytes no deben normalizarse antes de
calcular el hash.
